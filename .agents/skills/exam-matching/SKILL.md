# Exam matching

## Input
`courses/<CODE>/exams/*` (+ `exam-solutions/`), the course's slides/lecture notes for the topic list.

## Procedure
1. Build the topic list of the course from slide titles / syllabus (8–15 topics, stable names).
2. For each exam (read text with PyMuPDF; for scans render pages to PNG and read them visually):
   - list questions: number, short description (≤ 15 words), topic(s), points if written.
   - do not transcribe whole questions into committed files unless they are short; summarize.
3. Write `courses/<CODE>/exam-map.md` (committed, generated by you; mark it "generated"):
   - table per exam: `Soru | Konu | Kısa açıklama | Puan`
   - "En çok çıkan konular" ranking with counts across years
   - list of exams that could not be read (scanned, blurry)
4. Update each exam's metadata topics: `archive.py` has no edit command yet → open the `.meta.yaml` with your file
   edit tool and fill only the `topics:` list (do not change other fields), then run `archive.py validate`.

## Rules
- Topic names must be the same across years (use the topic list from step 1).
- If you cannot read a question, say so; never guess.
- No solutions unless an official/student solution exists (`exam-solution`); you may add short hints in Obsidian
  notes, not in the archive.
